Сюда кладутся скачанные файлы:

Название.mp3
Название.mp4

Имена без расширения должны совпадать. Регистр не важен.
Можно использовать один MP4 со встроенным звуком.
Для аудио без видео плеер показывает спектр.
Файлы берутся только из этой папки, без вложенных папок.

Если форматов с одинаковым названием несколько, выбирается один:
звук: FLAC, WAV, MP3, M4A, OGG, OPUS, AAC, WMA, AIFF;
видео: MP4, MKV, WEBM, MOV, AVI, M4V, MPEG, MPG.
