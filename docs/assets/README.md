# Artwork provenance

`visualizer.png` and `visualizer.gif` are generated by `scripts/render-demo.py`
using native ASIJI frames from `export_visualizer_demo`. Its audio input is
synthetic; no third-party recordings or video frames are used.

Project-specific artwork is available under the repository's MIT license to
the extent copyright applies. This does not license third-party font software
or trademarks.

Text in the checked-in images was rasterized using Windows system Consolas.
No font files, embedded fonts or reusable glyph atlases are distributed.
See the [Microsoft font FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq).
On Linux the development script can use an installed DejaVu Sans Mono font.
Pillow is a development tool, not a runtime dependency or bundled binary.
