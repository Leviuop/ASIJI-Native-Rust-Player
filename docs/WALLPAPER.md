# Живые обои

[← Главная](../README.md) · [Визуализатор](VISUALIZER.md)

В меню нажмите **S → Живые обои → true → W**, затем выберите трек.
Видео или визуализатор появится на рабочем столе. Терминал можно свернуть;
управление остаётся в нём: **Space** — пауза, **H** — ASCII/HD, **Q / Esc** —
убрать обои и вернуться в меню, **X / Ctrl+C** — выход. При своих биндах
используйте назначенные клавиши. Закрытие терминала завершает плеер.

По умолчанию обои выключены, а «Обои: система» имеет значение `auto`.
В Linux автоматический выбор учитывает окружение и тип графического сеанса.
Все интеграции пока экспериментальные: конкретный рабочий стол может иметь
особенности расположения значков, нескольких мониторов и версии оболочки.

| Окружение | Backend | Дополнительные компоненты |
|---|---|---|
| Windows 10/11 Explorer | `auto` | Не нужны; основной монитор |
| KDE Plasma 5/6, Wayland или X11 | `plasma` | Plasma и подходящий `qdbus`; собственный плагин ASIJI |
| Sway, Hyprland и другие Wayland-композиторы с layer-shell | `mpvpaper` | `mpvpaper` с поддержкой выхода `ALL` |
| GNOME Wayland 45–51 | `gnome` | Расширение ASIJI для GNOME Shell |
| Xfce, Cinnamon, MATE, LXQt и другие X11-сеансы | `x11` | `xwinwrap` и `mpv`; расположение относительно значков зависит от WM |

Это список реализованных интеграций, а не утверждение, что каждая версия
каждого окружения проверена на физическом компьютере. Wayland сам по себе
не предоставляет универсальный доступ к фону; GNOME не поддерживает layer-shell.
XWayland не заменяет интеграцию рабочего стола Wayland.

## KDE Plasma

При первом запуске обоев ASIJI устанавливает свой QML-плагин в
`${XDG_DATA_HOME:-~/.local/share}/plasma/wallpapers/io.github.Leviuop.asiji`.
Права root не нужны. Можно выполнить установку заранее:

```sh
./start.sh --wallpaper-backend plasma --wallpaper-setup
./start.sh --wallpaper true --wallpaper-backend plasma --mode blocks
```

Нужен `qdbus` той же версии Qt, что использует Plasma. Например, Ubuntu 22.04/24.04
с Plasma 5: пакет `qdbus-qt5`; Debian 13 с Plasma 6: `qdbus-qt6`.
В другом дистрибутиве используйте его пакетный менеджер.

Плагин включается на экранах текущей активности. При выходе ASIJI возвращает
предыдущий тип обоев; настройки прежнего плагина не перезаписываются. Если
вы сами сменили фон во время воспроизведения, ASIJI не отменяет ваш выбор.
После принудительного завершения процесса или сбоя сеанса выполните:

```sh
./start.sh --wallpaper-restore
```

Снимок прежнего типа обоев сохраняется в настройках плагина. Команда затрагивает
только рабочие столы, где всё ещё выбран ASIJI. Перезапуск Explorer/Plasma
и изменение экранов могут потребовать повторного запуска трека.

## Sway / Hyprland / layer-shell

Установите [mpvpaper](https://github.com/GhostNaN/mpvpaper) из пакетов дистрибутива
или по инструкции его проекта, затем:

```sh
./start.sh --wallpaper-backend mpvpaper --wallpaper-setup
./start.sh --wallpaper true --wallpaper-backend mpvpaper --mode blocks
```

ASIJI передаёт готовые кадры, а `mpvpaper` размещает их на выходах `ALL`.
Звук воспроизводит только ASIJI. При выходе дочерний процесс завершается.
Другие программы обоев могут конкурировать за тот же слой — остановите их
для этого сеанса. Автоматически чужие процессы не завершаются.

## GNOME Wayland

Установите расширение для текущего пользователя:

```sh
./start.sh --wallpaper-backend gnome --wallpaper-setup
gnome-extensions enable asiji@leviuop.github.io
```

При первой установке GNOME может не увидеть новое расширение до выхода и входа
в сеанс. После этого повторите команду включения и запустите трек с обоями.
Расширение также можно включить через приложение «Расширения».

Файлы находятся в `${XDG_DATA_HOME:-~/.local/share}/gnome-shell/extensions/asiji@leviuop.github.io`.
Расширение использует фон оболочки, не меняя системные настройки картинки;
при остановке плеера или потере соединения слой ASIJI убирается.
На экране блокировки анимация не рисуется. Поддерживаемые версии перечислены
в metadata расширения; обновления GNOME могут потребовать адаптации.

Отключение интеграции:

```sh
gnome-extensions disable asiji@leviuop.github.io
```

## X11

Установите `mpv` и [xwinwrap](https://github.com/mmhobi7/xwinwrap).
Далее выберите `x11` в настройках или запустите:

```sh
./start.sh --wallpaper true --wallpaper-backend x11 --mode blocks
```

Плеер создаёт отдельное окно рабочего стола без фокуса и ввода. Поведение слоя
относительно значков зависит от оконного менеджера. В KDE используйте `plasma`.
Нативный Wayland-сеанс с XWayland не принимается этим backend: выбирайте
`plasma`, `gnome` или `mpvpaper` по своему окружению.

## Качество, ресурсы и диагностика

В TOML доступны `wallpaper = true` и `wallpaper_backend = "auto"`.
При `width = 0` используются 320 столбцов независимо от размеров терминала.
Для уменьшения нагрузки укажите `--width 160 --fps 30`. В Linux ASCII использует
небольшой встроенный пиксельный алфавит ASIJI; HD отображает цветные пиксели.
В Windows ASCII использует системный моноширинный шрифт. Файлы шрифтов не поставляются.

Кадры Linux-обоев передаются без сжатия через случайный URL на `127.0.0.1`.
Сервер не открывается в сеть, не выдаёт файлы медиатеки и не принимает команды.
Медленный клиент не создаёт очередь кадров в плеере. Это локальный канал,
а не изоляция от других программ пользователя. Интернет во время воспроизведения
не требуется. Несколько экранов и большая ширина увеличивают расход памяти
и пропускной способности локального соединения.

Полноэкранные приложения пока не приостанавливают ASIJI автоматически.
Один пользователь может запустить только один Linux-сеанс обоев одновременно.
Обычный терминальный режим не требует дополнительных desktop-компонентов.
Автозапуск в систему не добавляется, пакеты и драйверы без команды пользователя
не скачиваются. Для ошибок GNOME смотрите журнал оболочки с сообщениями `ASIJI wallpaper`.

Основа интеграции Plasma описана в [официальном API](https://develop.kde.org/docs/plasma/scripting/api/),
поддержка layer-shell — в [документации протокольной библиотеки](https://github.com/wmww/gtk-layer-shell#supported-desktops).
Для разработчиков: [контракт и проверки Linux](LINUX-WALLPAPER.md).
