# Живые обои

[← Главная](../README.md) · [Визуализатор](VISUALIZER.md)

Экспериментальный режим для Windows 10/11 с рабочим столом Explorer.
Видео или визуализатор аудиотрека отображается под значками **основного монитора**.
По умолчанию режим выключен.

1. В меню треков нажмите **S**.
2. Стрелками выберите «Живые обои (Windows)» и переключите значение на `true`.
3. Выберите визуализатор, палитру и картинку: `ascii` — символы, `blocks` — цветной HD.
4. Нажмите **W**, затем выберите трек.

Терминал можно **свернуть**: музыка и анимация продолжат работать.
Чтобы управлять паузой, громкостью или перемоткой, вернитесь в терминал.
**Q / Esc** возвращают в меню и убирают обои; **X / Ctrl+C** закрывают плеер.
Это стандартные бинды — при переназначении используйте свои клавиши.
Закрытие окна терминала завершает и плеер.

Для обычного просмотра снова выключите настройку «Живые обои» и сохраните.
Файл системных обоев не меняется. ASIJI создаёт собственное окно, которое
удаляется при завершении воспроизведения; автозапуск в систему не добавляется.

```bat
start.bat --wallpaper true --mode blocks --visualizer orbit --visual-theme ember
```

В TOML: `wallpaper = true`. В режиме обоев `width = 0` означает 320 столбцов,
независимо от размера терминала. Свой предел задаётся `--width`; при рывках
уменьшите ширину или `--fps`. Для ASCII используется установленный системный
моноширинный шрифт; шрифты с программой не распространяются. HD выводится
через GDI, поэтому внешний вид отличается от терминальных полублоков.

## Ограничения

- Используется недокументированный слой Explorer (`WorkerW`). Обновления Windows
  и сторонние оболочки могут нарушить совместимость. Если слой недоступен,
  плеер сообщает об ошибке; обычное воспроизведение остаётся доступным.
- После перезапуска Explorer или изменения разрешения/расположения мониторов
  запустите трек заново. Выбор другого монитора пока не предусмотрен.
- Полноэкранные приложения не приостанавливают обои автоматически.
  Фоновая анимация расходует ресурсы, даже когда закрыта другими окнами.
- В Linux обои пока не поддерживаются: X11 и разные Wayland-композиторы требуют
  отдельных интеграций. Меню настроек, терминальная анимация и музыка работают
  на обеих платформах. Флаг обоев в Linux выдаёт явное сообщение об ограничении.

На Windows локально проверены слой Explorer, содержимое буфера ASCII/HD,
пауза, изменение размера терминала, индикация mute и удаление окна при выходе
в меню. Это не гарантия совместимости со всеми версиями Explorer и конфигурациями экранов.
