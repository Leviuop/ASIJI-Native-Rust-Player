# Права использования и распространения

[← Главная](../README.md) · [Third-party notices](../THIRD_PARTY.md)

Проверка: 24 сентября 2026 года, зависимости ASIJI 0.9.2 из Cargo.lock,
платформы `x86_64-pc-windows-msvc` и `x86_64-unknown-linux-gnu`.
Это техническая проверка комплектности лицензий, а не юридическое заключение
или гарантия отсутствия претензий.

## Код и зависимости

Собственный код ASIJI распространяется под [MIT](../LICENSE): разрешены
использование, изменение и распространение, включая коммерческое, при
сохранении уведомления об авторском праве и текста лицензии. Документация
и созданные для проекта демонстрационные изображения предоставляются на
тех же условиях в пределах прав на них. Чужие компоненты не становятся
собственностью автора ASIJI и не перелицензируются автоматически под MIT.

В проверенной конфигурации не выявлено условия зависимостей, требующего
перевести собственный код ASIJI с MIT на другую лицензию. Это относится
к указанному составу, а не к произвольным будущим форкам или поставкам.

Проверено по 104 записи разрешённого графа Cargo на платформу; число включает
инструменты сборки и не означает, что весь их код попал в бинарник.
Неиспользуемые Android/macOS-зависимости из общего lockfile не выдаются
за состав Windows/Linux-бинарника.

В готовой поставке:

- `licenses/INDEX.txt` — версии и лицензионные выражения;
- `licenses/DEPENDENCIES.json` — состав для платформы, ссылки на проекты,
  пути уведомлений и SHA-256 MPL-исходников;
- `licenses/<crate-version>/` — исходные LICENSE/NOTICE/COPYING;
- `licenses/rust-standard-library/` — уведомления стандартной библиотеки
  из использованного toolchain и сведения о компиляторе;
- `sources/*.crate` — полные неизменённые исходники пяти Symphonia-компонентов.

Для DEB эти каталоги находятся в `/usr/share/doc/asiji/`.

В выражениях с `OR` достаточно выполнить выбранную альтернативу: если
предлагается MIT, используется MIT. В `AND` обязательны обе части:
например, MIT **и** Unicode-3.0 для unicode-ident. CPAL и hound используют
Apache-2.0; применимые тексты лицензии, авторские уведомления и NOTICE
сохраняются. [Условия Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0).

Symphonia использует MPL-2.0. Пользователь получает исходники MPL-частей
в пакете, включая право изменять их на условиях MPL. Новые файлы приложения,
не содержащие MPL-кода, могут оставаться под MIT. При изменении MPL-файлов
нужно предоставлять соответствующие изменённые исходники, а не старые архивы.
[MPL 2.0](https://www.mozilla.org/en-US/MPL/2.0/) ·
[Разъяснения Mozilla](https://www.mozilla.org/en-US/MPL/2.0/FAQ/).

Уведомления Rust runtime учитываются отдельно от Cargo. Его состав и
исключения описаны в поставляемом `COPYRIGHT-library.html`; MIT проекта
их не заменяет. [Лицензии Rust](https://rust-lang.org/policies/licenses/).

## FFmpeg и системные компоненты

FFmpeg/FFprobe запускаются отдельными процессами; ASIJI передаёт обычные
медиа/PCM/RGB-данные, библиотеки FFmpeg в него не линкуются. Это основание
рассматривать их как отдельные программы. Изменение способа интеграции
потребует новой проверки. [GNU о взаимодействии программ](https://www.gnu.org/licenses/gpl-faq.html#MereAggregation).

Windows-лаунчер скачивает сборку Gyan 9.0.2 непосредственно у поставщика;
она обозначена GPLv3. После установки сохраняются `FFMPEG-LICENSE.txt`
и `FFMPEG-README.txt`. ZIP ASIJI не содержит этих бинарников. На Linux
FFmpeg, ALSA и glibc предоставляет дистрибутив; системные библиотеки
не копируются в наши пакеты.
[Сборки Gyan](https://www.gyan.dev/ffmpeg/builds/) ·
[Лицензирование FFmpeg](https://ffmpeg.org/legal.html).

**Не перепаковывайте установленную папку с FFmpeg как обычный MIT-релиз.**
При самостоятельном распространении этих бинарников необходимо выполнить
условия GPL для точной сборки, включая предоставление соответствующих
исходников, зависимостей и материалов сборки применимым способом.
Один URL на текущую ветку FFmpeg не доказывает выполнение этих требований.
Наш packaging script берёт только `asiji.exe`, а не всё содержимое `bin/`.

MSVC-сборка использует статический CRT. Код Microsoft runtime не становится
MIT-кодом; его распространение связано с условиями лицензированного toolchain.
Debug-runtime и SDK в поставку не входят. При собственной сборке проверьте
условия своего Build Tools: аудит репозитория не подтверждает лицензионный
статус чужой установки Windows/Visual Studio.
[Условия Microsoft](https://visualstudio.microsoft.com/license-terms/) ·
[Правила распространения](https://learn.microsoft.com/en-us/visualstudio/releases/2022/redistribution) ·
[Руководство по лицензированию](https://www.microsoft.com/licensing/guidance/Visual-Studio).

## Изображения, шрифты и медиа

`docs/assets/visualizer.png` и `.gif` созданы скриптом `scripts/render-demo.py`
из нашего рендерера и синтетического аудиосигнала. Чужие песни, кадры фильмов,
фотографии и записи рабочего стола в них не использованы. Pillow — инструмент
генерации, не часть поставляемого плеера. [Происхождение иллюстраций](assets/README.md).

В текущих изображениях подписи растеризованы системным Consolas. Файлов
шрифта, веб-шрифта или набора отдельных глифов в проекте нет. Microsoft
разрешает распространение изображений с текстом из системных шрифтов при
применимых условиях; это не разрешение копировать сам шрифт. На Linux
скрипт также может использовать установленный DejaVu Sans Mono.
[Microsoft Font FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq).

Значки GitHub Actions и Shields.io подключены ссылками; их код и шрифты
не включены в приложение. Названия сторонних продуктов обозначают
совместимость и не означают одобрения проекта владельцами товарных знаков.

Личных аудио/видео в проверенных пакетах и текущем репозитории нет.
Лицензия плеера не даёт прав на музыку, видео или их публичное исполнение.

## Границы проверки

- Патентные требования к кодекам зависят от страны и способа использования;
  авторская лицензия не снимает этот вопрос.
  [Пояснение FFmpeg](https://ffmpeg.org/legal.html).
- Поиск конфликтов названия ASIJI по реестрам товарных знаков не проводился.
- Полная экспертиза происхождения каждой строки кода и возможного сходства
  с чужими произведениями не проводилась; исключительные права на всё
  содержимое сборки не заявляются.
- Иные версии, собственные изменения и отдельно скачанные медиа требуют
  отдельной оценки.

## Перед собственной публикацией

Запустите `python scripts/test-licenses.py`, затем штатный packaging script.
Он блокирует неизвестные лицензионные выражения, отсутствующие уведомления,
изменённые MPL-исходники и несовпадение их SHA-256 с Cargo.lock.
Нужен компонент `rustup component add rust-docs`.

Распространяйте весь пакет с LICENSE, THIRD_PARTY.md, `licenses/` и `sources/`.
При новой зависимости сначала пересмотрите её условия, затем обновляйте
список проверенных выражений; не добавляйте их лишь ради зелёного CI.
Для коммерческой поставки с дополнительными кодеками, встроенным FFmpeg
или новым брендом разумна отдельная проверка профильным юристом.
